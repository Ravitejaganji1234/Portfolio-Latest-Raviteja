## 🖼️ Adding Your Profile Photo

1. Copy your photo to the `images/` folder
2. Name it `profile.jpg`
3. For best results: **square format**, at least **600×600px**, head & shoulders shot

If no photo is found, a styled initials placeholder ("RG") will show automatically.

## 🎨 Customization

In `index.html`, search for `ravitejaganji49@gmail.com`, `linkedin.com/in/raviteja-ganji`, and `github.com/Ravitejaganji1234` to update.

Search for `href="https://github.com/Ravitejaganji1234"` and update with your actual repo URLs.

### Add Project Screenshots
- Name them: `images/project-ecommerce.jpg`, `images/project-gitops.jpg`, `images/project-aks.jpg`

## 🌐 Hosting on LinkedIn

1. Host on **GitHub Pages** (free):
   - Push folder to a GitHub repo
   - Go to Settings → Pages → Source: main branch
   - Your URL: `https://yourusername.github.io/portfolio`

2. Add the URL to your LinkedIn profile:
   - Edit profile → Contact Info → Website → Add URL
